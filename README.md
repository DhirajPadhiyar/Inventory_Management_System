# Inventory Management System

## 📌 Overview

This is a web-based Inventory Management System built using ASP.NET Core MVC and Entity Framework Core.
It helps manage products, categories, and users efficiently.

---

## Features:
- Authentication (Login/Register)
- Role-based system (Admin & User)
- Admin: Add/Edit/Delete products
- Clean UI with Bootstrap
- Stock history tracking
- Secure using ASP.NET Identity
- Dashboard with low stock alerts

---

## 🛠️ Technologies Used

* ASP.NET Core MVC
* Entity Framework Core
* SQL Server
* C#
* Bootstrap 5

---

## Roles
Admin:
- Full access (CRUD)

 User:
- View only

## ▶️ How to Run

1. Clone the repository
2. Open in Visual Studio
3. Update connection string in `appsettings.json`
4. Run:

   * Add-Migration InitialCreate
   * Update-Database
5. Run the project
